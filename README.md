# Casa Verde

Site vitrine réalisé dans le cadre de mon apprentissage du développement web.

## Présentation

Casa Verde est un projet de site web pour une entreprise spécialisée dans la conception et l'entretien de jardins.

Le site présente différents services :

* Diseño de jardines
* Mantenimiento
* Instalación de césped
* Poda y cuidado

Une section présente également plusieurs projets réalisés ainsi qu'une section de contact.

## Technologies utilisées

* HTML5
* CSS3
* Flexbox
* Responsive Design
* Google Fonts
* GitHub
* GitHub Pages

## Objectif du projet

Ce projet a pour objectif de mettre en pratique les bases du développement web :

* structurer une page avec HTML ;
* créer une mise en page avec CSS ;
* utiliser Flexbox ;
* gérer les espacements, couleurs et typographies ;
* adapter le site aux différentes tailles d'écran ;
* utiliser Git et GitHub pour versionner et publier un projet.

## Mise en ligne

Le site est publié avec GitHub Pages.
